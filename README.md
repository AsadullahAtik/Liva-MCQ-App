# Live MCQ — মোবাইল অ্যাপ (Flutter): ছাত্র, শিক্ষক ও Admin

Spring সার্ভারের API দিয়ে চলে। একই অ্যাপে লগইনের ভূমিকা অনুযায়ী ছাত্র / শিক্ষক / Admin-এর পর্দা খোলে।

## যা পারে
- লগইন ও নিবন্ধন (শ্রেণি বেছে), সার্ভারের ঠিকানা অ্যাপেই বদলানো যায়
- পরীক্ষার তালিকা: শুরু করুন / চালিয়ে যান / আসছে / মিস / ফলাফল অপেক্ষমাণ / প্রকাশিত — **WebSocket-এ লাইভ আপডেট** (কেটে গেলে নিজে আবার যুক্ত হয়)
- পরীক্ষা: সার্ভারের ঘড়ি মেনে টাইমার, প্রতিটি উত্তর ২ সেকেন্ডে অটোসেভ, অ্যাপ ব্যাকগ্রাউন্ডে গেলে সেভ, সময় শেষে অটো-জমা, প্রশ্ন/অপশন shuffle সার্ভার সামলায়
- ফলাফল: নম্বর, র‍্যাংক, ভুল-শুদ্ধ পর্যালোচনা, র‍্যাংক তালিকা

## শিক্ষক ও Admin-এর অংশ
- **পরীক্ষা:** তালিকা (লাইভ), তৈরি ও সম্পাদনা (শ্রেণি, সময়, নম্বর, shuffle, শুরু/শেষের সময়, প্রশ্ন), প্রকাশ/প্রকাশ তুলে নেওয়া, মুছা, পরিসংখ্যান, **লাইভ ফলাফল-বোর্ড** (ছাত্র জমা দিলে সাথে সাথে আপডেট)
- **ছাত্র:** খোঁজা, প্রতিটি ছাত্রের রিপোর্ট; Admin ছাত্রের শ্রেণি/শাখা বদলাতে পারে
- **শ্রেণি** ও **শিক্ষক** ট্যাব শুধু Admin-এর: শ্রেণি/শাখা যোগ, শিক্ষক যোগ, শিক্ষকের শ্রেণি নির্ধারণ, মুছা
- শিক্ষক শুধু নিজের শ্রেণির পরীক্ষা ও ছাত্র দেখে (সার্ভার নিশ্চিত করে)
- ডেমো লগইন: Admin `admin/admin`, শিক্ষক `t1/1234`, ছাত্র `101/1234`

## পাসওয়ার্ড ও নিবন্ধন
- সবাই উপরের চাবি-আইকন থেকে নিজের পাসওয়ার্ড বদলাতে পারে
- Admin ছাত্রের রিপোর্ট পর্দা ও শিক্ষকের তালিকা থেকে যে কারও পাসওয়ার্ড রিসেট করতে পারে
- সার্ভারে `REGISTRATION_CODE` দিলে নিবন্ধনে "নিবন্ধন কোড" লাগে

## চালানোর ধাপ (Flutter ইনস্টল থাকতে হবে: `flutter doctor`)
```
cd live_mcq_app
flutter create --project-name live_mcq_app .   # android/ios ফোল্ডার বানায় (lib/ ও pubspec.yaml অক্ষত থাকে)
bash tool/patch_android.sh                      # HTTP সংযোগের অনুমতি + INTERNET (Android)
flutter pub get
flutter run
```
Windows-এ `patch_android.sh` না চললে `android/app/src/main/AndroidManifest.xml`-এ হাতে দিন:
- `<manifest>`-এর ভেতরে: `<uses-permission android:name="android.permission.INTERNET"/>`
- `<application` ট্যাগে: `android:usesCleartextTraffic="true"`

## সার্ভারের ঠিকানা
- Android emulator: `http://10.0.2.2:8080` (ডিফল্ট)
- আসল ফোন: কম্পিউটারের IP, যেমন `http://192.168.0.10:8080` (একই Wi-Fi; firewall-এ 8080 খোলা)
- লগইন পর্দার "সার্ভারের ঠিকানা" অংশে বদলান।
- ডেমো ছাত্র: রোল `101`, পাসওয়ার্ড `1234`।

## দ্রষ্টব্য
এই কোড Flutter SDK ছাড়া লেখা, তাই এখনো চালিয়ে/কম্পাইল করে দেখা হয়নি। `flutter run`-এ ত্রুটি এলে পুরো আউটপুট পাঠান।

## Flutter ইনস্টল ছাড়া APK বানানো (GitHub Actions)
1. GitHub-এ একটা নতুন repo বানান (private হলেও চলবে) এবং এই ফোল্ডারের সবকিছু (`.github` সহ) push করুন।
2. repo-র **Actions** ট্যাব → **Build APK** → **Run workflow**।
3. ৫–১০ মিনিট পরে সফল হলে রানের পাতার নিচে **Artifacts → live-mcq-apk** থেকে `app-release.apk` নামান (zip-এর ভেতরে)।
